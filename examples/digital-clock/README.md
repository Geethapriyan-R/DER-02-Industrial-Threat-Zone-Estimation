Digital World Clock

This is a minimal HTML + JavaScript example that displays the current time in multiple time zones and updates every second.

How to use

1. Open examples/digital-clock/index.html in a modern browser.
2. Use the dropdown or type a valid IANA timezone (e.g. "Asia/Kolkata") and click Add.
3. Remove timezones with the ✕ button on each card.

Notes

- The example uses the browser's Intl APIs to format times by timezone. Most modern browsers support the IANA timezone database.
- No build step required — just open the HTML file.
